01Agents and context

An agent is a harness around a frontier model, with tools and guardrails. It is not a chatbot bolted onto email.

Usefulness comes from depth of trusted context. Thin context produces generic answers. A secure, evolving context layer of mail, calendar, decisions and operating knowledge is what lets the model behave like someone who lives inside the work.

The aim: a continuously evolving, controlled context layer for Mario that can be used with current models, inside whatever stack IT approves.

02Hermes for Mario (proposal)

Hermes is the proposed chief-of-staff style assistant for Mario: brief priorities, support decisions with context, draft work, and act only with clear approval.

Demo ≠ proposal. The assistant in the demonstrations runs on Jason’s own development server with test data. It is not the proposed deployment. The proposed design, an AI model running inside a Milano Bro cloud account, has not been built, connected, or security-reviewed. It is on this page for discussion, not as something ready to switch on.

Outcome hoped for No decision is needed on this call. The useful result is a clear list from Romansas of the evidence and controls IT would need to see before approving anything, so the work can proceed in the order Romansas sets.

06Copilot: a question to look at together

Copilot is a reasonable default, and it is understandable that IT would prefer it: mail, calendar, Teams and meetings already live there. The narrower question is whether it covers the specific needs of this one personal pilot.

  • Multilingual handling, at the level Mario works in day to day
  • The degree of personalization Mario has described
  • Where a separate, evolving context layer would add something Copilot does not, if anywhere

To be looked at together, not argued to a conclusion. Which cloud account would host a model, if any, is IT’s call.

07Mario’s scope

Comfortable now

No other employees’ mailboxes. No SharePoint, OneDrive or broad document stores for now. Microsoft 365 access limited to what the pilot needs.

Required for usefulness

Eventually: Mario’s calendar; meetings and transcripts; Teams chats and channels; voice interaction.

Phased path

Phase 1 email → Phase 2 calendar and meetings → Phase 3 Teams → later phases add voice and deeper operating knowledge. Each phase carries its own security implications for Romansas to review.
